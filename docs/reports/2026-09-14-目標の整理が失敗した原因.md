# 目標の整理が失敗した原因

日付：2026-09-14
種別：調査・修正
状態：修正済み（本番への反映は push 待ち）

## 結論

原因は **整理APIの制限時間切れ** だった。

- 竜一さんの対話（39発言）を整理するのに、`claude-sonnet-5` で **75秒** かかった（実データで再現して測定）
- `/api/structure` の `maxDuration` が **60秒** だったため、Vercel が途中で関数を打ち切った
- 打ち切られると Vercel は JSON ではなく「An error occurred with your deployment ... FUNCTION_INVOCATION_TIMEOUT」という素のテキストを返す
- 画面側がそれを `res.json()` で読もうとして構文エラーになり、`Unexpected token 'A', "An error o"... is not valid JSON` が表示された
- さらに、失敗すると黙って1回やり直す作りだったので、同じく打ち切られ、待ち時間が約2分に延びていた

対話そのものは消えていない（整理が成功するまで保存したまま）。修正を本番へ反映すれば、同じ画面の「もう一度試す」で整理できる。

## 依頼と背景

竜一さんが目標の対話を最後まで進めて完了を押したところ、「あなたの言葉を整理しています…」の後に「整理できませんでした」と英語のエラーが出た（2026-09-14 0:23）。会話ログとAIの出力から原因を調べてほしい、という依頼。

## 調査結果

### 会話ログ（Supabase の同期データ）

- セッション `aa5e3570…`（小さな目標、コーチ：カエデ）
- 発言39件（ユーザー18件）、合計約3,500字。入力が大きすぎたわけではない
- 完了を押した時刻：2026-09-14 0:21（JST）
- 使用量の記録には、この対話でのコーチの応答（haiku）は残っているが、**整理（sonnet）の記録が1件も無い**。整理の呼び出しが一度も成功していない
- 整理が最後に成功した記録は 8/31 で、出力は 5,714 / 4,081 トークン。当時から60秒ぎりぎりだったと考えられる

### 実データでの再現

本番と同じプロンプト・同じスキーマ・同じモデルで、この対話を整理させて時間を測った（手元では60秒の打ち切りが無い）。

| 項目 | 値 |
|---|---|
| 所要時間 | 75.3秒 |
| 出力トークン | 6,681（うち思考 4,725） |
| 生成速度 | 約89トークン/秒 |
| 結果 | 正常に整理できた（`stop_reason: end_turn`） |

整理の中身に問題は無く、時間だけが足りなかった。出力の約7割が思考トークンで、これが時間の大半を占めている。

Vercel の実行ログそのものは、CLI にログインしていないため見ていない。上の再現と、エラー文言が Vercel の打ち切り時の文言と一致することから判断した。

## 変更内容

- `src/app/api/structure/route.ts`：`maxDuration` を 60 → 300 秒。理由と実測値をコメントに残した（Vercel は Pro プラン）
- `src/lib/api-response.ts`（新規）：応答の読み分け
  - JSON ならそのまま、またはサーバーのエラー文言を出す
  - JSON でない打ち切りは「整理に時間がかかりすぎて、途中で止まりました。対話は保存されているので、もう一度試せます。」と日本語で出す
  - 打ち切りや 4xx は自動でやり直さない（同じ条件で再送しても同じ結果になり、待ち時間と課金が倍になるだけ）。上流の一時的な 5xx だけ1回やり直す
- `src/app/card/page.tsx`・`src/app/big/page.tsx`：`res.json()` をやめて上の関数を使う。通信そのものが切れたときだけ1回やり直す
- `tests/api-response.test.mjs`（新規）：実際に返ってきた打ち切りの文面を含む7件。`npm test` に追加

## 仕組みの説明

1. 完了を押すと `/card` が対話全文を `/api/structure` に送る
2. サーバーは Sonnet に「3案ずつの言い方・WOOP・明日の一歩」をまとめて作らせ、**全部できてから** 返す
3. 生成が制限時間を超えると、Vercel が関数を止めてテキストのエラーを返す
4. 修正後は制限が300秒になり、75秒の整理は最後まで走る。万一また止まっても、画面には何が起きたかと、対話が残っていることが日本語で出る

## 残っていること

- **本番への反映**：push するまで、本番では同じ失敗が続く。反映後に「もう一度試す」を押せば、今回の対話から目標を作れる
- **待ち時間**：直しても整理には75秒前後かかる。思考トークンを減らす（または止める）と大きく縮むが、整理の質が落ちる可能性があるので、試すかは要相談
- **会話ログで気づいた別の問題（今回の失敗とは無関係）**：終盤で「もういいや」「これできめました」と返しているのに、コーチが同じ種類の質問（どんな時？何をする？）を続け、つまずきの場面から If-Then まで約10往復かかっていた。「決めた」「もういい」と言われたら締めに入る、という対話側の見直しが必要そう
