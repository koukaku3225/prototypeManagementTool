# 習慣の「月の見開き」を足す

日付：2026-10-10
種別：実装
状態：ローカルで動作確認済み。本番の確認は push 後（末尾の「確認できていないこと」を参照）

## 結論

習慣タブ（`/habits`）から開ける「月の見開き」画面（`/habits/month?m=2026-10`）を足した。
1か月を1枚に、行を習慣（長期目標ごとにまとめ、目標名の札つき）、列を日付にしたマス目で、
やった・最小版・できなかった・休み・未記録・予定のない日・まだ先・作る前を、
塗り・記号・枠の形・読み上げの併用で区別する。見るだけの画面で、保存データ・DB・同期は変えていない。

## 背景

習慣機能パターン集（`docs/mocks/2026-10-10-習慣機能パターン集.html`）の「4 記録」から、
R2「月の見開き」が選ばれた。直前の段（習慣タブの追加・習慣の作る形）の続き。
モックにあった「今月のひとこと」欄は、保存データを増やさないため作っていない。

## 仕組み

### マスの種別（`MonthCellKind`）

| 種別 | 意味 | 見た目（色以外の手がかり） |
|---|---|---|
| done | やった | 藍の塗り＋「✓」 |
| partial | 最小版 | 山吹＋「△」 |
| missed | できなかった | 赤み＋「×」 |
| skipped | 休み | 灰＋「休」 |
| unrecorded | 予定日だが記録なし（過去） | 実線の枠の空マス |
| open | 今日で、まだ記録なし | 山吹の破線の枠 |
| off | 予定のない日 | 小さな「·」 |
| none | 週N回の、記録のない日 | 小さな「·」（読み上げは「記録なし」） |
| future | まだ先 | 薄い破線の枠 |
| before | 作る前 | 斜線 |
| after | やめたあと | 斜線 |

- **記録が優先。** 作る前・やめたあと・未来・予定外でも、記録があれば記録の状態を出す。
  「やったのに空欄に見える」を作らないため。曜日指定の習慣で決めた曜日以外にやった日は、角に点を付ける。
- **週N回は予定のない日にしない。** 曜日を決めない約束なので、やった日だけを塗り、ほかは空欄のままにする。
- **作成日はローカル日付。** `habitStartDate()`（UTC の `createdAt` をローカル日付に直す）を通す。
  `toISOString().slice(0, 10)` は使っていない。

### 数字の要約

習慣ごとに「その月にやった回数（done＋partial）」と達成率を出す。数え方は `habit.ts` の
`computeRate` / `weekRate` と同じ約束に揃えた（別の数え方だと、習慣タブと見開きで率が食い違う）。

- 日で数える習慣: 予定日が分母。休みは外す。今日の未記録は入れない。作成日はやった記録があるときだけ入れる。
  予定外の日にやった分は回数には入るが率の分子には入れない（100%超を防ぐ）。
- 週N回: **月に丸ごと収まり、終わっていて、作った週でない週**だけで、週の目安を分母にして数える
  （1週の分子は目安で頭打ち）。月の頭と終わりで切れる週は率に入れない（回数には入る）。
  そういう週が無い月は率を出さず回数だけ。
- 立ち上がり14日（`isWarmingUp`）は率を出さず「立ち上がり中」と出す。判断の基準日は
  「今日」ではなく「その月の終わり（または今日）」。今日で見ると、9月の見開きの率が10月に入った途端に出てしまう。

### どの習慣を出すか（自分で決めた方針）

- 進行中の習慣: その月の終わりより前に作っていれば出す。作る前の月は出さない。
- **畳んだ習慣・完了した目標の習慣: その月に記録があるときだけ出す。**
  消すと「あの月はこれをやっていた」が見えなくなる（畳むのは、続かなかったことも記録だから）。
  一方、記録の無い月まで出すと、やめた習慣が空のマスで並び続けて見開きが「やっていないこと」で埋まる。
  畳んだ日より後のマスは、未来も含めて「やめたあと」にする。
- 完了した目標の習慣は、やめた日が分からないので日付では「やめたあと」にしない（記録の有無だけで出し入れする）。

### 画面

- 左の習慣名（と要約）は固定、日付の列だけ横にスクロール。幅は 420px 固定の画面でも崩れない。
  月の列数（28〜31）に合わせて表の幅が変わるだけ。
- 今月を開くと、今日の列が日付領域の真ん中に来るようにずらす。今日の列は見出しと列に色を付ける。
- 月曜の列に区切り線。前の月・次の月ボタン、「今月にもどる」。
  前へは習慣・記録のある最古の月まで、次へは今月まで。
- 月は `?m=2026-10`。`location.search` から読む（`/plan` と同じ。Suspense 境界が要らない）。
  `abc`・`2026-13` などは今月に戻す。
- 下タブは増やしていない。`/habits` 配下なので「習慣」タブが光る。

実操作で見つけて直したこと:

1. 今日の列を中央に寄せる計算が、描画直後の列幅で狂って別の日付が中央に来た。
   `requestAnimationFrame` で幅が定まってから、固定した習慣名の幅を除いて合わせるようにした。
2. 畳んだ習慣の未来の日が「まだ先」の空欄で並び、記録できそうに見えた。「やめたあと」を優先するようにした。
3. 「予定のない日」の記号がダークモードでほとんど見えなかった。色を `text-muted/60` にした。
4. 「習慣を作る前の月です」の注記が、未来の月でも出る条件になっていた。最古の月との比較に直した。
