## 直したこと

### 1. 週N回の習慣が、守っていても半分以下に見えていた

**症状**：`週3回` の習慣を**毎週ちょうど3回、5週続けた**記録で、

- わたし画面：「**2日連続** ・ 保険を使用中 ・ **45% 直近30日** ・ 予定29日」
- 今日の画面：習慣の横に「**2日**」

一度も約束を破っていないのに、達成率は半分以下、連続はほぼゼロ、
そのうえ「保険を使用中」（＝途切れかけている合図）まで出ていた。

**原因**：数える単位が日のままだったこと。`isScheduled()` が
「週N回は曜日を問わないので、**どの日も予定日**」と答えていたため、

- 達成率の分母が30日ぶん（実測29日）になり、週3回なら上限が 3/7＝43% に潰れる
- 連続は「やらない日」が来た時点で途切れるので、週3回では最大2日にしかならない
  （保険で1日守っても3日目で切れる）

**直し方**：**週N回だけ、数える単位を週にした**（`countsByWeek`）。

- 連続 … 目安に届いた**週**の数。今週はまだ途中なので、届いていなくても途切れにしない。
  作った週は途中から始まっていて届きようがないので、数えずに止める。
  保険は日のときと同じく1回だけで、守れるのは直前の週まで
- 達成率 … **終わった直近4週**を、週の目安（回数）を分母にして数える。
  1週に目安より多くやっても、その週ぶんは目安どまりで数える（前倒しで水増ししない）。
  今週を入れないのは、日のときに「今日ぶんはまだ結果が出ていない」として
  分母から外しているのと同じ理由
- 画面は単位まで出しわける（「5週連続」「100% 直近4週」「予定12回」）。
  出しわけないと「3週連続」を「3日連続」と読ませてしまう

毎日・曜日指定の習慣は今までどおり日で数える（表示も変わらない）。

### 2. 目標の一覧・森の「次の予定」に、消された予定が出ていた

**症状**：Googleカレンダーで消された予定（「Googleで削除済み」と薄く残る枠）が
これから来る時間に入っていると、目標の一覧（`/goals`）と森の
**「次の予定」がその消えた予定を案内**していた。時間の合計（今週・累計）からは
9/19 の修正で外れているので、**合計に入っていない予定を「次にやること」として先頭に出す**
という食い違い方をしていた。

**直し方**：合計と同じ基準（`countsAsPlanned`）を通す。
判断を `timebox.ts` の `upcomingBoxes()` に出して、画面はその結果を並べるだけにした。
中間目標タブは前から正しく外していた（`countsForCheckpoint`）ので、これでそろった。

なお、目標の詳細の予定タブはこれと違って**一覧**なので、消された予定も
「Googleで削除済み」と印を付けて出す（9/20 の修正のまま）。

### 3. 知らないコーチIDで、画面が丸ごとエラーになっていた

**症状**：コーチのアイコンは配色の表（`LOOKS`）を引いて描いている。
表に無いIDだと表引きが空になり、`look.bg` を読んだ時点で例外になる。
エラー境界がその画面を丸ごと「うまく表示できませんでした」に差し替えるので、
**目標の一覧・目標の詳細・履歴・大きな物語がそろって開けなくなる**。
本人には理由も直し方も分からない（データは無事なのに画面だけ失う）。

IDは本人が選ぶものだけとは限らない。

- クラウドから取り込む行（`mappers.ts` は `coach_id` を検証せずそのまま `CoachId` として扱う）
- 設定画面の「JSONを貼り付けて読み込む」で入ってくる値

**直し方**：配色の表と「知らないIDのときどうするか」を
`src/lib/coach-look.ts` に分け、`coachLook()` が**表に無いIDなら既定の顔を返す**ようにした。
アイコン1つのために画面を失うほうが損なので、知らないIDは既定の顔で描いて先へ進む。
描画（`.tsx`）から分けたのは、この判断をテストで固定できるようにするため。

## 仕組みの説明

3件とも「同じ1つの事実を、置き場所ごとに別々に決めていた」ことが原因。

```
Habit（繰り返すこと）
 └ schedule.kind
     ├ daily / weekdays … 曜日が決まっている → 日で数える
     └ timesPerWeek     … 曜日を決めない    → 週で数える   ← 今回1（日で数えていた）

TimeBox（予定1件）
 └ sourceGoneAt が入っている＝Google側では消えた
     ├ 時間割・今日・目標の詳細 … 「Googleで削除済み」・合計から外す
     ├ 中間目標タブの「次：」   … 出さない
     └ 目標の一覧・森の「次の予定」… 普通の予定として出す      ← 今回2

CoachId（コーチのID）
 └ 配色の表に無い
     ├ 既定の顔で描く   … これまで無かった
     └ 表引きが空のまま … SVGが落ちて画面ごとエラー画面      ← 今回3
```

判断そのもの（`countsByWeek` / `upcomingBoxes` / `coachLook`）を関数に寄せ、
画面はその結果を出すだけにした。
