# 中間目標タブ

日付：2026-09-17
種別：機能追加
状態：実装・ローカル確認済み。本番反映は下記

## 結論

下タブに「中間目標」を足した（今日｜中間目標｜目標｜わたし）。
目標を今週・今月の**測れる目安**（時間／回数／達成）に分け、時間割の予定とつなげる。
期間が終わった中間目標は、結果を見ながら「続ける／目安を変える／終わりにする」を選ぶ。

- 設計：[docs/superpowers/specs/2026-09-17-checkpoint-tab-design.md](../superpowers/specs/2026-09-17-checkpoint-tab-design.md)
- モック：https://claude.ai/artifact/8vGERNoGBCShCjSBJKQnEd

## 背景

目標はあっても、今日やることが「何のためか」につながらず、ブレイクダウンが弱かった。
週・月の中間目標（Checkpoint）はすでにあったが、目標の詳細を開かないと見えず、
数値の目安も、時間割とのつながりも持っていなかった。

## 仕組み

- **時間**：紐づけた予定の合計（予定を入れた時点で数える）。完了した時間は内訳で出す
- **回数**：完了した紐づけ予定の数 ＋「＋1」で足した数
- **達成**：チェック（status を done に）
- 数えるのは、非表示でなく日付が期間内の予定だけ
- **振り返り**：達成していれば done、未達なら abandoned（既存の「今回は終わりにする」）で閉じる。
  続けるなら今の期間で新しく作る。今の期間に同じものが既にあれば作らず、「目安を変える」ならそちらの目安を変える

## 検証

| 確認 | 結果 |
|---|---|
| `npm test`（中間目標 43件・マッパー 12件ほか全件）・`tsc`・`next build` | 通過 |
| ローカル（スマホ幅）で一覧の表示 | ✅ 5.5 / 10時間（完了4.5）、先週 7.5 / 10時間 を表示 |
| 振り返り「目安を変えて続ける → 8」 | ✅ 先週は終わり、今週の目安が8に。二重に作られない |
| 回数の「＋1」・達成のチェック・足す（回数3回／今月） | ✅ |
| 「予定に入れる」→ 予定シート → 保存 | ✅ 目標と中間目標が入った状態で開き、保存後 6 / 8時間 |
| コンソールのエラー | なし |

途中で見つけて直したもの：
- チェックした「達成」が一覧から消えて取り消せなかった → できたものも一覧に残す
- 振り返りで、今週に同じ中間目標があると二重に作られた → 作らず、目安を変える場合はそちらを変える
- 過去に完了した予定があるのに「紐づけた予定はまだありません」と出た → 「この先の予定はまだありません」

## 残件

- 目標の詳細画面の中間目標エディタでは、測り方・目安をまだ編集できない（タブで足したものは表示・引き継ぎされる）
- 今日の画面の「いまの中間目標」に進み具合（数値）はまだ出していない
- 振り返りで目安を変えても、タイトル（例「週10時間」）は自動では変わらない
