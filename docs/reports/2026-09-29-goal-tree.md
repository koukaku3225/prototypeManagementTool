# 目標ツリー（親目標）を入れた

## 結論

目標カードどうしを親子にできるようにし、目標一覧と森の絵をツリーとして見せるようにした。
達成済みは既定で畳み、親に数だけ出す。設計は
[2026-09-29-goal-tree-design.md](../superpowers/specs/2026-09-29-goal-tree-design.md)。

## 決めたこと

竜一さんの選択は次の5つ。

- 親子は目標カードどうし。深さは自由（暴走よけに上限5段）
- 「進行中は3つまで」の枠は、進行中の子を持たない目標だけ数える
- 達成済みは既定で畳み、親に「達成 n」とだけ出す
- 森の絵は親＝幹、子＝大枝（小枝＝中間目標、葉＝習慣、根＝価値観は据え置き）
- 親は入れ物。中間目標・習慣・予定は一番下の目標に付ける

Dラボ側の知見（「三日坊主を防ぐ曖昧目標」「ストレッチゴールは有害」）から、
深さを無制限にはせず上限を設けた。

## 変更内容

- `src/lib/goal-tree.ts`（新規）… 親子の判定をすべてここに集約。循環禁止・深さ上限・
  葉の数え方・達成済みの畳み・親を消したときの子の昇格。壊れたデータ（親が居ない・
  輪になっている）でも止まらないように書いてある
- `src/types/goal.ts` … `GoalCard.parentId` を追加（既存データはキー自体が無い＝根）
- `src/lib/storage.ts` … `canAddGoal` を葉の数で判定。`deleteCard` は子を消さず親なしに上げる
- `src/app/goals/page.tsx` … リストを字下げのツリーに。親の行に「下にnつ」、
  達成済みは「達成 n」を押すと開く
- `src/app/goal/[id]/page.tsx` … 見出しの下に親へのリンクと子の数。背景の中に親目標を選ぶ欄
- `src/lib/forest.ts` / `forest-draw.ts` / `GoalForest.tsx` … 親＝幹、子＝大枝で描画。
  達成済みの子は枝を描かず付け根に実でまとめる。枝の先が画面外に出ないよう向きと長さを調整し、
  空の上に出る子の名前は白で縁取り
- `src/lib/supabase/mappers.ts` … `parent_id` の受け渡し
- 本番Supabase … `goal_cards.parent_id`（text, null可）を追加（竜一さんの承認を得て実行）

## 検証結果

- `npm test` 全件通過（`tests/goal-tree.test.mjs` 21件、`tests/forest.test.mjs` に親子の4件を追加）
- `npx tsc --noEmit` 通過、`npx next build` 通過
- ローカルの本番ビルド（別ポート3210・本人のデータに触れない空のブラウザ）で実際に操作して確認:
  - 親子が字下げで並び、親に「下に2つ」、達成済みは「達成 1」で畳む・開く
  - 枠の判定が葉だけになり、親2つ＋葉3つで「枠が3つとも埋まっています」
  - 森に幹＝親、大枝＝子が描かれ、子の名前が読める。達成済みは実のかたまり＋「達成1」
  - 親目標の選択で付け替えが保存される。候補に自分の子孫は出ない
  - 親を消すと「下の1つの目標は消えず、親なしに戻ります」と出て、実際に子と子の習慣が残った
- 本番URL（https://prototype-management-tool.vercel.app 、ログインしていない空のブラウザにテストデータを入れて確認）:
  - リストが親子の字下げになり、親に「下に2つ」「下に1つ」。「達成 1」を押すと達成済みの子が開く
  - 枠は「残り1枠」（葉は2つ。親2つは数えない）
  - 森に幹＝親、大枝＝子が描かれ、子の名前（note発信・記事を10本書く・卓球で勝つ）と
    畳んだ達成済みの「達成1」がすべて画面内に収まっている
  - 目標ページに「↑ note発信」と親へのリンクが出て、親目標の選択欄の候補から自分の子孫が外れている
  - コンソールにエラーなし。確認後、テストデータは消した
