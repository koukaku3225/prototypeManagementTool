# 対話の上限と逃げ道・書き出し案内（R10・R11）

日付：2026-09-14
種別：実装
状態：完了（AI の実応答での効果確認は未実施）

## 結論

- **R10**：目標づくりの最後のステップ（障害と明日の一歩）の上限を 7→10 ターンに上げた。
  あわせて、対話画面に2つのボタンを足した。
  - **別の質問にする**：くどい・答えようのない質問を、答えずに切り替えてもらう。押してもターンに数えない
  - **切り上げて次へ（非推奨）**：上限まで話さずにステップを終える。最後のステップでは「ここで終える（非推奨）」になり、対話が完了して整理に進む。確認を1回挟む
  - コーチ全員に共通の決まりとして、同じ型の質問を続けない、根っこの欲求に着いたら「なぜ」を掘り続けない、「もういい」と言われたら先へ進める、を足した
- **R11**：未ログインで何か作ってある人にだけ、わたし画面に「データはこの端末のブラウザにしか残っていません」と「いま書き出す」ボタンを出すようにした

## 依頼と背景

「R10 y（ただし強制完了ボタンを追加。ユーザーには非推奨。質問パターンが同じで、どうでもよい分析ループに入るときがあるので回避して。
例：なぜ彼女が欲しい→〇〇したいから→なぜ〇〇したい→したいから！のように根源に着いたら深掘りは不要。
質問を変えるボタンが欲しい）」「R11 y」。

- R10：上限7では、問い直しが1回入るだけで「いつ・どこで」を聞く前に打ち切られていた
- R11：デプロイ環境で未ログインだと、データの安全網が無い。書き出しは設定画面の下にしかなかった

「強制完了」は、**いまのステップを切り上げる**形にした（最後のステップなら対話全体が完了）。
最初のステップからいきなり対話全体を終えると、具体化も明日の一歩も空のまま整理に回り、目標カードがほぼ空になるため。

## 仕組みの説明

**別の質問にする**：押すと「（この質問は置いておいて、別の角度から聞いてください）」という発言が会話に残り、
サーバーには `rephrase: true` が届く。サーバーは「直前と同じ型の問いをしない、別の切り口から1問だけ」という指示を足してコーチに返させる。
この往復はターンに数えないので、何度押しても上限は近づかない。
押せるのは、コーチが問いを出して返事を待っているときだけ（応答の途中・完了後は出ない）。

**切り上げて次へ**：押すと「おすすめしません。まだ決まっていないことがあると…空欄になります」と確認が出る。
「切り上げて次へ進む」で次のステップへ移り、コーチが自動で次の問いを出す。
最後のステップなら「ここで対話を終える」で完了し、いつもどおり整理へ進む。
「次へ」の案内が出ているときは正規の進み方があるので、このボタンは出さない。
応答の取得に失敗し続けているときは押せる（抜けられないと困るため）。

**書き出し案内**：ログインしていない、かつ目標・習慣・対話など何か1つでもあるときだけ出す。
何も作っていない人には守るものが無いので出さない。ボタンは設定画面の書き出しと同じ JSON を保存する。

## 確認したこと

**テスト**：追加20件は先に書き、実装前に失敗することを確認した（上限の3件、未実装の関数・定数の読み込みエラー）。
`npx tsc --noEmit` エラーなし、`npm test` 全件通過（517件）、`npm run build` 成功。

**ブラウザでの実操作**（開発サーバー。AI の課金を避けるため、`/api/chat` と `/api/structure` はページ内で偽の応答に差し替えた）
- 対話の途中（具体化のステップ、コーチが「なぜ〇〇したいのですか？」で待っている状態）に「別の質問にする」「切り上げて次へ（非推奨）」が出る
- 「別の質問にする」→ 送信内容は `rephrase: true`、会話に「（この質問は置いておいて…）」が残り、コーチの新しい問いが続く。**ターン数は 2 のまま**
- ふつうに「週に2回」と返す → ターン数が 2→3 に増える
- 「切り上げて次へ」→ 確認文が出る →「話を続ける」で何も変わらない
- もう一度 →「切り上げて次へ進む」→ 次のステップ（障害と明日の一歩）に移り、コーチの最初の問いが自動で出る
- 最後のステップではボタンが「ここで終える（非推奨）」になり、確認文も「目標カードの一部が空欄のまま作られます」に変わる
- 「ここで対話を終える」→ 対話が完了し、「あなたの言葉を整理しています…」から整理画面（`/card`）へ移る（整理の API は偽の応答で止めた）
- わたし画面：何も無いときは案内が出ない。目標を1つ入れると出る。「いま書き出す」で `goal-coach-state-2026-09-14.json`（約700バイト）が作られ、「書き出しました」が出る（実際のダウンロードはページ内で止めた）
- スマホ幅（375px）でボタンが折り返さず読めることを見て、狭い画面で文字が縦に崩れていたのを直した
- 確認後、ブラウザの検証データを消し（アドレスが localhost であることを確かめてから）、`.local-backups/` を確認前のコピーで戻して一致を確認

**確認できていないこと**
- AI の実際の応答で、「別の質問にする」が本当に違う角度の質問になるか、原則の追加で「なぜ」の堂々巡りが減るか。
  課金を伴うため、偽の応答でしか通していない（R5・R18）。一度実際の対話で試してほしい
