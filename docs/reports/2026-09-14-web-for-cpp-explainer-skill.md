# C++経験者向けWeb技術説明スキルの作成

日付：2026-09-14
種別：設定変更
状態：完了

## 結論

Web技術をC++経験者へ説明するとき、C++との対応、Webでの意味、日常の比喩、このアプリの実例、対応の限界という順で説明する `web-for-cpp-explainer` スキルを追加した。

## 依頼と背景

ユーザーはNext.js初学者であり、今後のWeb技術説明ではC++や一般的なシステム開発を足場にしたい。また、電車の待ち時間や顧客から受け取る一次情報など、身近な状況も使って理解しやすくしたいという希望があった。

## 変更内容・調査結果

- C++・システム開発との近い概念を最初に示す。
- ブラウザとサーバーの担当を明確にする。
- 話題に適した日常の比喩を1つ選ぶ。
- このアプリの実装を確認できる場合は、実ファイルを読んで例示する。
- 比喩と実物が異なる点を明示し、誤解を防ぐ。
- 一般例や仮定を、このアプリの実装済み機能として断定しない。

スキルなしの基準確認ではC++とレストランの比喩は提示できたが、比喩の限界と、実装確認済みの事実・仮例の区別が弱かったため、これらを明文化した。

## 仕組みの説明

説明対象を、既知の概念から未知の概念へ順に対応づける。例えばCookieは「クライアント側に保存され、対象のHTTP要求へブラウザが自動添付する小さな値」と説明し、C++のHTTPクライアントが共通ヘッダーを付ける処理や、受付でもらう入館証を補助的に使う。最後に、人が任意に提示する入館証とは違ってブラウザが自動送信する点を示す。
