# 目標ページの縦スクロール短縮（案A＋小さな改善）

## 結論
目標詳細ページ（`/goal/[id]`）を「触る頻度順」に並べ替え、読み返す頻度の低い部分を畳んだ。案の比較は [2026-09-14-goal-page-layout-proposals.html](2026-09-14-goal-page-layout-proposals.html)。

## 背景
縦に長く、毎日触る予定・習慣が一番下に埋もれていた。ユーザー指示: 「短い呼び名」UIの削除、「大きな物語とのつながり」「これが大事な理由」を一番下へ・非表示に。

## 変更内容
- 「短い呼び名」ブロックを削除（`card.label` のデータと時間割での表示は残す）
- 新しい並び: なりたい姿（期限バッジ「あと◯日」つき）→ ジャンプ用チップ → 木（幅240pxに縮小・「大きく」で拡大・凡例は「木の見かた」に格納）→ 予定 → 繰り返すこと → 中間目標 → つまずき → 目標の中身 → 背景（畳む）→ その他の操作（畳む）
- 予定は「今日以降の未完了3件」だけ出し、「過去・完了も含めて全N件を見る」で全件表示
- つまずき0件のとき「まだありません」を出さず、追加ボタン1行だけにした
- ブロックの内側余白と間隔を少し詰めた
- `deadlineCountdown()` を `src/lib/date.ts` に追加し、テストを `tests/date.test.mjs` に追加

## 関連ファイル
- `src/app/goal/[id]/page.tsx`
- `src/lib/date.ts` / `tests/date.test.mjs`
