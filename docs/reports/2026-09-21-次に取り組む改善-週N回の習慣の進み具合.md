## 依頼と背景

このアプリの目的は「対話で決めた目標を、時間割・習慣・振り返りで行動に移す」こと。
昨日（2026-09-21 未明）の修正で、週N回の習慣は**達成率と連続を週で数える**ようになった（`countsByWeek`）。
ただし、その数え方の変更は「わたし」画面の集計だけに効いていて、**毎日開く今日の画面と、記録の格子には届いていなかった**。

## 現在の問題（実施前）

### 1. 今日の画面：週3回を守っていても「今日の習慣 0/1」が居座る

- **誰が・どこで**：週N回の習慣を持つ人が、毎日開く今日の画面（`/list`）で
- **何が起きるか**：週N回の習慣は `isScheduled()` が常に true を返すため、**毎日「今日の習慣」に出る**。
  月・火・水で3回やり終えた週でも、木曜以降は「今日の習慣 0/1」のまま。約束は守っているのに未完了に見える
- **もう一つ**：「今週あと何回か」がどこにも出ていなかった。今日やるべきかを本人が数えるしかない

### 2. わたし画面：記録のない日が「できなかった」のように並ぶ

ヒートマップは、予定日で記録のない日を空欄の枠で描く。週N回は毎日が予定日扱いなので、
**きっちり週3回やっている人でも、1週7マスのうち4マスが空欄の枠**になる。
読み上げ（`aria-label`）も「予定35日に対して15日できています」と、実際の約束と違う数字になる。

## 変更内容

### 1. 今週の進み具合と、今日の一覧の扱い

- `HabitStats` に `thisWeek: { done, target } | null` を追加。週N回だけ、今週の月曜〜日曜の
  done / partial の回数と目安を持つ（`skipped` は数えない。日のときと同じ）
- 今日の一覧に出すか（`dueToday`）は、週N回だけ「**今週の目安に届いていない、または今日すでに記録した**」
  ときに限る。届いた週の残りの日は出さない。**今日押した記録は残す**（押した結果が消えると、押したのか分からなくなる）
- 習慣のカードの副題に「20分 ・ 週3回 ・ **今週 2/3回**」を出す

毎日・曜日指定の習慣は `thisWeek` が `null` で、今日の一覧の出方も変わらない。

### 2. ヒートマップ

週N回は曜日を決めないので、`heatmap()` が返す `scheduled` を false にした（記録のある日には今までどおり色が付く）。
読み上げは、予定日が0のときは「直近35日のうち、○日できています」と言う。

## 仕組みの説明

```
週3回の習慣（木曜に今日の画面を開く）
 ├ 月・火・水に3回やった   → 今週 3/3 → 今日の一覧に出ない（以前は「0/1」が残った）
 ├ 月・火に2回やった        → 今週 2/3 → 今日の一覧に出る「今週 2/3回」
 └ 今日「できた」を押した   → 今週 3/3 でも、今日の一覧には残る（押した結果を見せる）
```
