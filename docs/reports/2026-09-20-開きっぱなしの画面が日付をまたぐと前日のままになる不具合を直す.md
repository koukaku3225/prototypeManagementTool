# 開きっぱなしの画面が、日付をまたいでも前日のままになる不具合を直す

日付：2026-09-20
種別：修正
状態：一部完了（コードとテストは完了。**日付をまたぐ実機（ブラウザ）での確認は未実施**）

## 結論

**今日・時間割・目標・目標の詳細・中間目標・わたしの6画面が、開いた瞬間に1回だけ「今日」を読み込み、
その後は日付が変わったことを知らなかった。** スマホで開いたまま寝て、朝にアプリへ戻ると
前日の予定が「今日」として出たままになる。

画面が見える状態に戻ったとき・フォーカスが戻ったとき・履歴から復元されたとき・30秒ごとに、
日付が変わっていないかを見て、変わっていたらその画面のデータを読み直すようにした
（`useDayRollover`）。日付が同じあいだは何もしない。

`npm test` 704件・`npx tsc --noEmit`・`npm run build` は通った。
**ただし、この定期実行では開発サーバーを起動できず、実際に日付をまたぐ操作は見ていない**
（下の「確認したこと」「残っていること」）。

## 依頼と背景

`daily-next-plan`（次に取り組む改善を選び、判断の要らないものは実施する定期タスク）の 2026-09-20 実行分。

コードから言えるのは「起きうる経路が確かにある」ことまで。

### 症状（コードから読み取れる範囲）

- 夜に「今日」の画面を開いたまま画面を消す（タブ・ホーム画面のアプリが残る）
- 翌朝、アプリを開き直さずに戻る
- **今日の画面**：前日の予定・習慣・中間目標が「今日」として並ぶ。いまの時間の帯は時計で動く
  （`nowMinutes` を30秒ごとに更新している）ので、**前日の予定表に今の時刻の線が引かれる**
- **時間割**：選んでいる日が前日のまま。「今日」の印も付かず、習慣から自動で並ぶ枠も前日のもの
- **目標・目標の詳細**：「次の予定」に前日の予定が残る、今週の合計や「期限まであと○日」も前日基準
- **中間目標**：週や月が変わったのに、終わった期間を「いま」として出す
- **わたし**：連続日数・「今日はまだ」が前日の数え方のまま

`AGENTS.md` の「日付」の節は、まさに「今日やることが深夜に消える」を防ぐために
`today()` を通すよう決めている。ただしそれは「`today()` を呼んだ瞬間の日付が正しい」ことしか
守っていない。**呼んだあと画面が読み直されなければ、正しい `today()` でも古いまま残る**。

## 変更内容

| 種類 | 中身 |

| 目標（`/goals`）・わたし（`/me`）・中間目標（`/checkpoints`） | 読み込み処理を `reload` に切り出し、日付が変わったら呼ぶ |
| 目標の詳細（`/goal/[id]`） | **読み直さず、描き直すだけ**。データは日付で変わらず、読み直すと編集中の入力を保存済みの中身で差し替えかねないため。`today` を state にして、「これから来る予定」「期限まで」「木の今日の状態」だけ数え直す |

`useDayRollover` を各画面が使うだけで、画面ごとに日付を見る処理を書き足さない作りにした
（`残件` 9/20 棚卸しで直した「同じ事実を画面ごとに数え直して食い違う」と同じ轍を踏まないため）。

## 仕組みの説明

```
画面を開く ── 「今日」= 2026-09-20 を読み込み、番人がその日を覚える
   │
   │  （夜のあいだ画面は裏に回る。ブラウザは裏のタイマーを止めることがある）
   │
朝、アプリに戻る ─▶ visibilitychange / focus / pageshow が起きる
   │
番人.check() ── いまの日付（ローカル）= 2026-09-21 ≠ 覚えていた 2026-09-20
   │            └▶ 画面の onNewDay(2026-09-21, 2026-09-20) を1回呼ぶ
   ▼
画面が読み直し ── 覚える日を 2026-09-21 に進める（同じ日のあいだは呼ばない）
```

- 「裏のタイマーが止まる」ので、30秒ごとの確認だけでは足りない。**画面に戻った瞬間の確認が主役**で、
  30秒ごとの確認は、開いたまま日付をまたぐ場合の保険。
- 日付は **ローカル**で数える（`toLocalDate`）。`toISOString()`（UTC）だと、日本では朝9時まで
  前日と判定してしまう（`AGENTS.md` の「日付」の節）。
- 「後の日になったか」ではなく「読み込んだ日と違うか」で見る。端末の日付やタイムゾーンを
  変えて戻った場合も、食い違えば読み直す。
