# 今日の画面に中間目標を出す（R19）

日付：2026-09-14
種別：実装
状態：完了

## 結論

今日の画面のいちばん上に「いまの中間目標」を出すようにした。

- 期間が今日を含む、終わっていない中間目標を**期限の近い順に最大2件**。どの目標のためかを小さく添える
- **期間が過ぎたのに「完了／今回は終わり」を付けていないもの**は、「期間が終わりました　振り返る →」として先頭に出す
- 3件以上あるときは「ほかN件 →」で目標一覧へ。押すと目標の詳細へ移る
- 1件も無ければ見出しごと出さない

## 依頼と背景

`残件.md` の R19「中間目標（週/月）が日々の画面のどこにも出てこない」。
置き場所の案4つ（A 今日の画面の先頭／B 予定シート／C わたし画面／D 期限間近だけ）を出し、
竜一さんの選択で **A だけ**を作った。B・C・D は作っていない。

中間目標の入力欄は「分解しておくと、期限が近づいたときに今なにをやるべきか迷わなくなります」とうたっているのに、
実際には目標の詳細と目標一覧でしか見えず、毎日開く画面には出ていなかった。

## 仕組みの説明

出す条件（`todayCheckpoints`）：

1. 状態が「活動中」（完了・今回は終わりは出さない）
2. 見出しが空でない
3. ぶら下がっている目標が、完了も削除もされていない
4. 期間がもう始まっている（来週分はまだ出さない）

並べ方：期限切れを先に出し、次に期限の近い順に並べる。期限が同じなら週を月より先に出す。上から2件を出し、残りは件数だけ返す。

期限切れを先に出すのは、閉じないまま放っておくと「残り0日」のまま居座り続けるから。押すと目標の詳細に移るので、そこで「完了にする」か「今回は終わりにする」を選べる。
