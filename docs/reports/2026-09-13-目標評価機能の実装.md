# 中期目標（Checkpoint）の建て方を評価する機能の実装

日付：2026-09-13
種別：実装
状態：完了

## 結論

前回の設計（[2026-09-13-目標評価機能の設計.md](./2026-09-13-目標評価機能の設計.md)）どおり、`Checkpoint`に任意の評価パネルを実装した。3軸（動機・価値観・人との関わり）を独立して自己採点でき、既定は畳んだ状態で、更新の主導線には影響しない。

動機の4問はDaiGoの動画から「同一化・内的・取入的・外的」という**分類の枠組み（Sheldon & Elliotの学術モデル）だけ**を借り、実際の質問文・補足文・リフレーミング文言はすべて書き下ろした（竜一さんからの指摘を受けて、初期の設計案から文言を差し替え済み）。

実機で動機スライダー・価値観チップ・人との関わりトグルすべてを操作し、`localStorage`への保存とスコアのリアルタイム表示を確認した。

## 依頼と背景

竜一さんの依頼「目標の建て方を評価する機能」について、知識収集→設計→文言の書き直し（著作権への配慮）を経て、「続けてください」の指示で実装に進んだ。

## 変更内容

### データモデル

`src/types/goal.ts` に `CheckpointEvaluation` を追加し、`Checkpoint.evaluation?: CheckpointEvaluation | null` として埋め込んだ（`TimeBox.review`と同じ考え方）。

```ts
export interface CheckpointEvaluation {
  motives: { identified: number; intrinsic: number; introjected: number; external: number }; // 各1〜10、既定5
  linkedValues: string[];   // 大きな物語の価値観のうち関連するもの
  whyItMatters: string;
  hasBuddy: boolean;
  buddyNote: string;
  updatedAt: string;
}
```

### 計算（純粋関数、`src/lib/checkpoint.ts`）

- `selfConcordanceScore(motives)`：`(identified + intrinsic) - (introjected + external)`
- `scoreTone(score)`：±6を境に`good`/`neutral`/`warn`の3値。文言は責めない言い方にした
- `isEvaluated(evaluation)`：一度でも触ったか（未評価は要約を出さない判定に使う）
- `evaluationSummary(evaluation)`：畳んだ見出しに出す1行要約（例:「動機+6・価値観2件・仲間あり」）。触っていない項目は言わない

### UI

- `src/components/CheckpointEvaluationPanel.tsx`（新規）：4本のスライダー（`<input type="range">`）＋価値観チップ＋人との関わりの2択ボタン。すべて触った瞬間に保存する（一言欄だけ`EditableField`の編集確定方式）
- `src/components/CheckpointEditor.tsx`：各Checkpointの操作行の下に`<details>`（既定は畳む）でパネルを差し込んだ。要約は`isEvaluated`/`evaluationSummary`で見出しに出す
- `src/app/goal/[id]/page.tsx`：`CheckpointEditor`に`bigStoryValues={big?.values ?? []}`を渡すように変更

### 文言について

初期の設計案はDaiGoの動画の質問文に近い言い回しだったため、竜一さんの指摘（「パクると怒られるから」）を受けて全面的に書き直した。借りているのは「4分類に分ける」という学術的な枠組み（Sheldon & Elliotのセルフコンコーダンスモデル）のみで、日本語の文言はすべてこちらのオリジナル。

| 動機 | ラベル（書き下ろし） |
|---|---|
| 同一化 | 自分で選んだと言える |
| 内的 | やっている最中が楽しい |
| 取入的 | やらないと落ち着かない |
| 外的 | 誰かの目や見返りが理由 |

## 仕組みの説明

1. `/goal/[id]`のCheckpoint行に「たて方を評価する」という折りたたみが増える。既定は閉じている
2. 開くと、動機4本のスライダー・価値観チップ・人との関わりトグルが並ぶ
3. スライダーを動かすたびに`patch()`が呼ばれ、`upsertCheckpoint()`経由で`localStorage`に即保存される。専用の保存ボタンは無い
4. スコアがマイナス（-6以下）のときだけ、目標を変えずに捉え方を変えることを勧める一言が出る
5. 評価済みのCheckpointは、畳んだ状態の見出しに「動機+6・価値観2件・仲間あり」のように要約が出る。未評価なら何も出ない
