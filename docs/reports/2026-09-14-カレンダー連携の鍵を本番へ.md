# カレンダー連携の鍵を本番へ入れた

日付：2026-09-14
種別：設定変更＋スクリプト修正
状態：同意画面の手前まで完了（残りは本人の「許可」）

## 結論

本番の設定画面に出ていた「鍵が設定されていません」の警告は**消えた**。
「Googleカレンダーと連携する」を押すと、Google のアカウント選択画面へ進むところまで確認した。

## やったこと

| 項目 | 内容 | 確認方法 |
|---|---|---|
| Google Calendar API | **無効だった**。本人が有効化 | コンソールで「API が有効です」を確認 |
| リダイレクトURI・テストユーザー | 設定済みだった（変更なし） | クライアント詳細・対象ページを読んだ |
| スコープ登録 | 手動追加欄に入力まで準備。保存はされていない | テスト中アプリなのでテストユーザーは登録なしで同意できる |
| Vercel 環境変数 | 7変数 × production/preview を `.env.local` から反映 | `vercel env pull` した値と `.env.local` を sha256 で照合し全一致 |
| 再デプロイ | `vercel redeploy`（直前の本番ビルドを再利用） | 本番 `/api/calendar/connect` が 307 で Google 認可URLへ。scope は `calendar.app.created` と `calendar.readonly` |

preview 側にも変数が入ったので、「プレビューが500になる」持ち越し課題も同時に解消した。
Upstash のトークンも有効な値で上書きされた。

## スクリプトの修正（`scripts/push-env-to-vercel.sh`）

Vercel CLI 50.23 では `vercel env add NAME preview` が「どのブランチか」を聞いて止まり、
案内どおり `--value … --yes` を付けても止まる。第3引数に空文字を渡すと「全 Preview ブランチ」で通る。
値は標準入力ではなく `--value` で渡す形にした。
