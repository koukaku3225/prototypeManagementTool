# 目標ツリー（親目標）設計

2026-09-29。目標カードどうしを親子にし、森の絵と一覧をツリーとして見せる。

## 決めたこと（竜一さんの選択）

- 親子は**目標カードどうし**。深さは自由（安全のため上限5段）
- 「進行中は3つまで」の枠は、**進行中の子を持たない目標だけ**数える
- 達成済みは**既定で畳む**。親に「達成 12」と数だけ出し、押すと開く
- 森の絵は**親＝幹、子＝大枝**（小枝＝中間目標、葉＝習慣、根＝価値観は今のまま）
- **親は入れ物**。中間目標・習慣・予定は一番下の目標に付ける

## データ

`GoalCard.parentId?: string | null` を足すだけ。親は子の一覧を持たない
（`upsertCard` がカードを丸ごと置換するため、親側に配列を持つと子の追加で競合する）。

不変条件:
- 自分の子孫を親にできない（循環禁止）
- 根からの深さは5段まで
- 親を消しても子は消さない。子は `parentId = null` に上がる
- 親の完了は自動でやらない。子が全部完了したとき画面で尋ねる

クラウド同期には `goal_cards.parent_id`（text, null可）の追加と `mappers.ts` の対応が要る。
列を足すまで、親子はその端末にだけ残る。

## 画面

- `/goal/[id]`: 「親目標」欄。候補は自分と自分の子孫を除いた進行中の目標
- `/goals` リスト: 字下げのツリー。親の行に「達成 n」。押すと達成済みの子が開く
- `/goals` 森: 親＝幹から子＝大枝。達成済みの子は枝を描かず、付け根に実としてまとめる
- `/goal/new`: 親を選んでから作れる（枠の判定は葉だけ）

## 検証

- 純粋関数（`src/lib/goal-tree.ts`）にテストを書く: 循環・深さ・葉の数え方・達成済みの畳み
