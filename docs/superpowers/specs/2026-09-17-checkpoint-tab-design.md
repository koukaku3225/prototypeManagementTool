# 中間目標タブ — 設計

作成日: 2026-09-17　モック: https://claude.ai/artifact/8vGERNoGBCShCjSBJKQnEd

## 目的

目標はあるが、今日やることが「何のためか」につながらない（ブレイクダウンが弱い）。
目標を今週・今月の**測れる目安**に分け、時間割の予定とつなげる。

## 決めたこと（竜一の選択）

| 論点 | 決定 |
|---|---|
| 置き場所 | 下タブ「今日｜中間目標｜目標｜わたし」 |
| 測り方 | 中間目標ごとに 時間／回数／達成 を選ぶ |
| 予定との紐づけ | タブの「予定に入れる」と、予定シートの「どの中間目標か」の両方 |
| 引き継ぎ | 期間が終わった中間目標を結果つきで並べ、続ける／目安を変えて続ける／終わりにする を選ぶ |
| 見た目 | 既存デザインのまま |
| 時間の数え方 | 予定を入れた時点で数える（完了した分も内訳で出す） |

## データ

既存の `Checkpoint`（週/月の中間目標）を広げる。新しい仕組みは作らない。

- `Checkpoint.measure?: "time" | "count" | "done"` … 無ければ `"done"`（既存データ）
- `Checkpoint.target?: number | null` … 時間は時間数、回数は回数。達成は null
- `Checkpoint.manualCount?: number` … 回数を手で＋1したぶん
- `Checkpoint.previousId?: string | null` … 引き継ぎ元（振り返りの履歴をたどる用）
- `TimeBox.checkpointId?: string | null` … どの中間目標のための予定か
- Supabase: `checkpoints.measure / target / manual_count / previous_id`、`timeboxes.checkpoint_id`（外部キーは張らない。中間目標を消しても予定は残す）

## 進み具合（純粋関数 `checkpointProgress`）

紐づけた予定のうち、非表示でなく、日付が期間内のものだけを数える。

| 測り方 | 値 | 達成 |
|---|---|---|
| 時間 | 予定の合計時間（完了した時間も別に返す） | 値 ≥ 目安 |
| 回数 | 完了した予定の数 ＋ 手で足した数 | 値 ≥ 目安 |
| 達成 | status が done なら 1 | status が done |

## 画面

1. `/checkpoints`（新タブ）: 期間が終わって閉じていないもの（振り返り）を先頭に、今の期間の中間目標を目標ごとに並べる。行ごとに進み具合・「予定に入れる」（`/plan?checkpoint=<id>`）・回数の「＋1」・達成のチェック。「中間目標を足す」シート。
2. 予定シート: 「どの中間目標か」。その予定の目標にぶら下がり、予定の日付を期間に含む活動中のものを選べる。
3. `/plan?checkpoint=<id>`: 今日の次の空き時間に、目標と中間目標を入れた新しい予定を開く。

## 振り返り（純粋関数 `closeAndCarryOver`）

- 閉じる中間目標の status は、達成なら done、そうでなければ abandoned（「今回は終わりにする」の既存の意味）
- 続けるなら、今日を含む同じ種類の期間で新しい中間目標を作る（同じタイトル・測り方、目安は同じか変えた値、previousId に元の ID）

## やらないこと

- 目安の自動提案、週をまたいだグラフ、通知
